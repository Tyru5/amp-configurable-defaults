# Feature screenshots

Captured October 24, 2026. Live images are real, signed-in Amp in Helium at
1280 × 800 image pixels. Privacy masks hide conversation content, thread names,
and account details; task/output text is hidden. Pane positions are unchanged.
These are layout evidence, not claims that every pictured auxiliary tool works
end to end. No credentials or private thread content should be published.

## Suggested five store uploads

1. [Right sidebar and child hierarchy](right-sidebar.png). Native parent/child
   rows remain in their order; children are indented. The header master icon
   and resize divider remain visible.
2. [Wider right sidebar](right-resized.png). Captured after a real pointer drag
   changed the sidebar to 380px. Double-click reset is tested separately.
3. [Subagents on the left](right-subagents.png). Two actual subagents, selection,
   task/output sections, and right-side navigation. Content is hidden for privacy.
4. [Subagents on the right](left-subagents.png). Left navigation reverses the
   reading panel's side. The panel is optional and closes back to inline content.
5. [Master behavior off](master-off.png). Native left navigation and row spacing
   return; the header master icon remains available to turn behavior on again.
